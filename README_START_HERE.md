# Thirupathi Reddy — Dark Portfolio (No Dragon)

A dark, professional portfolio focused on UI/UX experience, projects and downloadable resume.

## Publish on GitHub Pages
1. Remove the old website files from the repository (leave repository and Pages configuration in place).
2. Upload all files and the assets folder from this package to the repository root.
3. Keep `CNAME` and `index.html` at the root; commit the changes.
4. Verify GitHub Actions/Pages deployment; refresh https://thirupathireddy.com/

## Content
- Homepage: professional introduction and typographic hero art (no dragon)
- Experience: Chase, UPMC, Amazon India, Brillio
- Project: CareConnect concept case study
- Resume: Direct DOCX download (`assets/Thirupathi_Reddy_UIUX_Resume.docx`); no resume viewer
- Contact: email and LinkedIn only

The uploaded resume document is used as supplied. Check its contact links before publishing.
