# Thirupathi Reddy — Rebuilt Portfolio

This revision features your professional UI/UX experience from the shared UIUX Resume(2).docx, a standalone resume page, CareConnect case study, and an integrated homepage dragon. The mascot is **not** a separate Projects card.

## Install on GitHub Pages
Upload **all files inside this folder** (not the outer folder) to the root of the repository GitHub Pages publishes. Open Settings > Pages, choose main / root. Leave the existing CNAME in place for thirupathireddy.com.

## 3D dragon troubleshooting
The 3D version imports Three.js from a CDN and needs network and WebGL. A 2D animated SVG dragon is always shown if 3D fails. Test with a desktop browser, disable extensions blocking jsDelivr, check F12 Console for import/graphics errors. The CSS fallback should make a visible mascot even when CDN unavailable. The test in this package checks syntax and static rendering, not live WebGL.
